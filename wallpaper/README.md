# Jewbuntu wallpapers

`Jewbuntu-day.jpeg` and `Jewbuntu-night.jpeg` are original artwork made for Jewbuntu:
layered wave shapes with a heavy Gaussian blur, rendered from `source/*.svg` by
`source/render-wallpapers.sh`. Licence: CC BY-SA 4.0, Jewbuntu Developers.

They replace upstream MacTahoe's macOS wallpapers, which this fork does not ship.

Install to GNOME's background picker: `./install-gnome-backgrounds.sh`

`Jewbuntu-star-blue.png` ("Cream Star of David on Blue Waves") and
`Jewbuntu-star-purple.png` ("Luminous Star in Purple Waves") were supplied by the
Jewbuntu project owner (1586×992). Licence and origin to be confirmed before a
public release; until then treat them as "all rights reserved, Jewbuntu project".
